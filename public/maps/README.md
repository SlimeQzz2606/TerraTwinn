# Country overlay

`countries.geojson` is generated by `scripts/fetch_country_boundaries.py` from
[Natural Earth Admin 0 Countries, 1:50m](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/).
Source archive: https://naturalearth.s3.amazonaws.com/50m_cultural/ne_50m_admin_0_countries.zip

Natural Earth data is public domain. Geometry is simplified by 0.035 degrees
with topology preservation for globe display. English names and label positions
come from the source attributes. The 242 records include map units/territories;
this is not a count of sovereign states. Boundaries follow the source's default
de facto cartography and are for orientation, not legal boundary determination.
This overlay is not used in terrain ranking or measurements.
